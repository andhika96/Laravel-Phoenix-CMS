Ya, saya sudah cek dan uji langsung di web demo Elementor. Kontrol tersebut memang asli Elementor, tetapi efeknya sangat bergantung pada layout parent.

| Opsi | Fungsi | Mengapa terlihat tidak bereaksi |
|---|---|---|
| Width | Mengatur lebar widget | `Default` biasanya memenuhi lebar parent |
| Align Self | Mengatur posisi widget pada cross-axis Flexbox | Tidak terlihat jika widget masih selebar parent |
| Order | Memindahkan urutan widget terhadap sibling | Tidak terlihat jika Accordion satu-satunya widget |
| Size Grow | Mengisi ruang kosong parent Flexbox | Tidak terlihat jika tinggi/lebar parent mengikuti isi |
| Size Shrink | Memperkecil widget saat ruang parent tidak cukup | Tidak terlihat tanpa kondisi overflow |
| Column/Row Span | Membentangkan widget dalam parent Grid | Tidak berfungsi pada parent Flexbox |

Hasil pengukuran di Elementor resmi:

- `Align Self: Center` mengubah CSS menjadi `align-self:center`, tetapi Accordion tetap selebar sekitar `1125px`, sehingga tidak tampak bergerak.
- Setelah `Width: Inline (auto)`, Accordion mengecil menjadi sekitar `184px` dan langsung berpindah ke tengah.
- `Order: Start` mengubah posisi Accordion dari `y ≈ 274px` menjadi `y = 0` karena ada widget Tabs sebagai sibling.
- `Size: Grow` mengubah `flex-grow` dari `0` menjadi `1`, tetapi tinggi tetap sama karena parent tidak memiliki ruang ekstra.
- `Column Span` dan `Row Span` benar-benar disembunyikan Elementor ketika parent adalah Flexbox (`display:none`).

Jadi ada satu kesalahan nyata pada editor kita: [AdvancedControls.vue](D:/Laragon/www/laravel-13-phoenix/public/js/pagebuilder_elementor/widgets/shared/AdvancedControls.vue:15) menampilkan `Column Span` dan `Row Span` tanpa memeriksa apakah parent-nya Grid. CSS-nya memang dihasilkan oleh [app.js](D:/Laragon/www/laravel-13-phoenix/public/js/pagebuilder_elementor/app.js:529) dan [WidgetAdvancedStyleResolver.php](D:/Laragon/www/laravel-13-phoenix/app/Support/PageBuilderElementor/WidgetAdvancedStyleResolver.php:109), tetapi browser mengabaikan properti Grid tersebut ketika parent masih Flexbox.

Ada juga opsi lain yang memang tidak selalu mengubah tampilan canvas:

- `Z-Index`: baru terlihat jika elemen saling bertumpuk.
- `Sticky`: terlihat ketika halaman di-scroll.
- `CSS ID`, `CSS Classes`, dan `Attributes`: tidak mengubah visual tanpa CSS/JavaScript yang menggunakannya.
- `Display Conditions` dan `Cache Settings`: memengaruhi frontend/rendering, bukan tampilan langsung canvas.
- `Position: Absolute/Fixed`, Margin, Padding, Width, Background, Border, dan Transform seharusnya memberikan perubahan canvas langsung.
