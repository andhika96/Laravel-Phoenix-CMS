Tiga pendekatannya:

1. **Image Source pada widget — rekomendasi**
   - Pilihan `CKFinder` dan `External URL`.
   - Ringkas, jelas, dan hanya mengubah Image widget v2.3.

2. **Tambahkan “Insert from URL” ke CKFinder**
   - Paling mirip WordPress.
   - Jauh lebih kompleks karena memodifikasi file manager global, bukan hanya widget.

3. **Tampilkan CKFinder dan URL bersamaan**
   - Paling cepat dibuat.
   - Membingungkan karena pengguna tidak tahu sumber mana yang aktif.

Rancangan yang saya rekomendasikan:

- Tambahkan **Image Source** tepat di atas kontrol gambar.
- Default: **CKFinder**, sehingga data dan perilaku lama tidak berubah.
- Jika memilih **External URL**, tampilkan input `Image URL` dengan contoh URL langsung dan pembaruan canvas secara live.
- CKFinder dan URL memakai satu nilai akhir `src`.
- Berpindah sumber tidak langsung menghapus gambar saat ini; gambar baru akan menggantikannya.
- **Alt** tetap tersedia.
- **Link, Caption, Image Resolution, dan Lightbox** tidak ditambahkan dalam pekerjaan ini agar scope tetap sempit.
- Hanya v2.3 yang berubah; v2.0 tetap utuh.
- Akan ditambahkan regression test untuk kontrol, kompatibilitas data lama, canvas, dan frontend remote image.

Restart laptop akan menghentikan semua proses Graphify/Git yang sedang menumpuk, jadi setelah restart kondisinya bersih.

- Restart: membersihkan proses yang sedang macet.
- Perbaikan hook: mencegah masalah terulang.
- Pastikan simpan pekerjaan lain sebelum restart. Commit Git yang sudah dibuat tidak akan hilang.
