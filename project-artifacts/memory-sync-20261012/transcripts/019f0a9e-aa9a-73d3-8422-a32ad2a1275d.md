- Target: `https://www.mgmotor.id`
- Total gambar: `64`
- Lazy-loaded: `24`
- Coverage lazy-load: `37.50%`
- Belum optimal: `40` gambar masih dimuat langsung

- Native `loading="lazy"` belum dipakai
- Format gambar sudah cukup baik: banyak yang sudah `WebP`

- Performa browser saat dites: DOM ready sekitar `2.4s`, full load sekitar `3.4s`

Rekomendasi optimasinya:

- Tambahkan `loading="lazy"` ke gambar non-critical/below-the-fold.
- Pertahankan gambar critical/above-the-fold sebagai eager load.
- Tambahkan placeholder/fallback agar gambar tidak blank kalau lazy-load gagal.
- Migrasi bertahap dari Vue LazyLoad ke native lazy loading.
- Jika migrasi selesai, hapus Vue LazyLoad untuk mengurangi overhead sekitar `30KB` JS.
- Test ulang dengan browser, PageSpeed, dan Core Web Vitals.
