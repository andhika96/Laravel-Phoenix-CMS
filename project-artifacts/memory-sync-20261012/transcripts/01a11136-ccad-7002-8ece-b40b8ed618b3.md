Untuk mengosongkan status yang sudah dipilih:

1. Klik sel berisi **Pending** atau **Done**.
2. Tekan **Delete** pada keyboard. Kalau dropdown sedang terbuka, tekan **Esc** terlebih dahulu.
3. Isinya menjadi kosong, tetapi dropdown tetap tersedia untuk dipilih lagi.

Warna status tetap otomatis: **Pending kuning dengan teks cokelat**, **Done hijau dengan teks hijau tua**. Kolom Keterangan tetap kosong.

Untuk **font kecil pada daftar pilihan yang muncul di screenshot**, itu merupakan batasan dropdown *Data Validation* bawaan Excel. Font popup-nya tidak bisa diubah seperti font sel. Memperbesar **zoom Excel** dapat membantu keterbacaannya. [Penjelasan pada Microsoft Q&A](https://learn.microsoft.com/en-gb/answers/questions/4762108/how-to-format-text-in-a-drop-down-box).

Pengaturan kosong, ukuran font 14 pt, dan kedua aturan warna sudah diperiksa dalam file hasil ekspor; seluruh **92 baris** tetap dipertahankan. Interaksi tombol Delete belum diuji langsung pada aplikasi Excel Anda.
