**Ya, boleh dan tepat dijalankan melalui Supervisor aaPanel** agar worker GIS tetap hidup tanpa terminal terbuka. Gunakan **path lengkap ke `artisan`** supaya tidak bergantung pada direktori awal proses:

```bash
/usr/bin/php /www/wwwroot/itbumdev.web.id/artisan queue:work gis-imports --queue=gis-imports --sleep=3 --timeout=600 --memory=256
```

Isi konfigurasi Supervisor seperti berikut:

| Pengaturan | Nilai |
|---|---|
| Nama program | `itbumdev-gis-imports` — edit program lama yang masih STOPPED |
| Working directory / Run directory | `/www/wwwroot/itbumdev.web.id` |
| Command | Command lengkap di atas |
| User | User aplikasi yang memiliki akses baca/tulis ke `storage` dan `bootstrap/cache`; samakan dengan worker aplikasi yang sudah berjalan jika permission-nya benar |
| Jumlah proses / `numprocs` | **1** |
| Autostart | Aktif |
| Autorestart | Aktif |
| `stopwaitsecs`, jika tersedia | **900** |

Pada source lokal yang sudah diperiksa, connection `gis-imports` memiliki **`retry_after = 900` detik**, lebih panjang daripada timeout job **600 detik**. **Pastikan konfigurasi yang sudah di-deploy ke VPS juga sama** di `config/queue.php`; nilai ini mencegah job yang masih berjalan terlalu cepat diambil ulang.

Urutan penerapannya:

1. **Jika worker manual dari command sebelumnya masih berjalan**, tunggu pekerjaan aktif selesai lalu hentikan dengan `Ctrl+C`, sebelum menyalakan worker Supervisor. Jika belum pernah dijalankan, lewati langkah ini.
2. Edit program **`itbumdev-gis-imports`** yang STOPPED memakai konfigurasi di atas, simpan, lalu Start.
3. **Biarkan `itbumdev-queue` tetap RUNNING** untuk pekerjaan umum aplikasi.
4. Periksa log worker GIS dan progres import. Status Supervisor `RUNNING` perlu disertai bukti `ProcessOilPalmTreeImport` diproses dan progres halaman berubah.
