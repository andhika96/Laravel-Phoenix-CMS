### 4. Header kanan dan profil — sebagian sehat

![Menu profil Arunika v3](D:/Laragon/www/laravel-13-phoenix/output/playwright/arunika-v3-audit/03-profile-menu-open.png)

- Implementasi menampilkan palette, dark mode, notifikasi, lalu avatar kecil.
