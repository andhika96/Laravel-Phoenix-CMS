## Perubahan utama

### 1. Tipografi mengikuti CMS

Panel tidak memakai ukuran font mandiri yang terlalu besar atau terlalu kecil. Semua ukuran diwariskan dari:

- `--ph-adaptive-font-size`
- fallback `--ph-font-size`
- fallback akhir `1rem`

Skala relatif yang dipakai:

- Nilai input dan select: `1em`
- Label: `0.9em`
- Helper/description: `0.82em`
- Line-height helper: `1.5`
- Tinggi form dan action: `2.5rem`, setara 40px pada root standar
- Switch tetap memakai geometri yang sudah disetujui: 44×24px, dengan setting row yang menyediakan area interaksi lebih longgar

Dengan pendekatan ini, font panel akan tetap serasi ketika theme CMS mengganti ukuran atau font family.

### 2. Spacing, padding, dan margin

Kontrak layout sekarang diseragamkan:

- Padding panel desktop: `20px 24px 24px`

### 3. Grouping form lebih jelas

Setting tidak lagi terlihat sebagai daftar field yang mengambang. Pola berikut sekarang digunakan secara konsisten:

- Border tipis menggunakan border token CMS/Bootstrap

- Editorial Journal — Thumbnail position

Input angka dan unit sekarang mempunyai tinggi, border, radius, dan proporsi yang konsisten. Native number spinner disembunyikan secara visual agar tidak memenuhi field, tetapi input tetap `type="number"` dan masih mendukung keyboard.
