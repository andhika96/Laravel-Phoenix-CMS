Saya sudah cek dari terminal. Hasilnya:

- SSD USB terbaca sebagai `ESD310C TS256GESD310C`, ukuran sekitar 256 GB.
- Filesystem-nya `exFAT`, label volume `Andhika G`.
- Scan `chkdsk E:` berhenti di 84% dengan pesan snapshot error.
- Setelah scan gagal, Windows tidak lagi me-mount volume `E:`.
- Event log juga mencatat warning I/O retry untuk `Disk 1`, jadi kemungkinan koneksi USB/port sempat drop atau filesystem exFAT-nya kotor/corrupt ringan.

Jangan format drive-nya.

Langkah berikutnya:

1. Cabut SSD portable.
2. Tunggu 10-15 detik.
3. Colok langsung ke port USB laptop/PC, jangan lewat hub.
4. Kalau muncul notifikasi Windows, jangan klik format.
5. Kalau drive sudah muncul lagi, backup dulu file penting kalau masih bisa dibuka.
6. Setelah itu jalankan repair dari PowerShell/CMD **Run as Administrator**:

```powershell
chkdsk E: /f /x
```

Kalau setelah dicolok ulang huruf drive berubah, ganti `E:` sesuai huruf barunya.

Saya belum menjalankan perintah repair karena drive-nya sekarang sudah tidak termount, dan `chkdsk /f /x` akan mengubah metadata filesystem. Setelah kamu colok ulang SSD-nya, bilang ke saya drive letter yang muncul, nanti saya bantu lanjut cek dan repair.
