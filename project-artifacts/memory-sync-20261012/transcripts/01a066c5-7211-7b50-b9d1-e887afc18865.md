## 2026-09-03 17:17:31 WIB — Laporan akhir assistant

Cara paling mudah memakai Adobe Acrobat Reader:

1. Simpan foto tanda tangan sebagai **PNG/JPG**—PNG transparan lebih rapi.
2. Buka PDF di Adobe Acrobat Reader.
3. Pilih **Fill & Sign / Isi dan Tanda Tangani**.
4. Klik **Add Signature → Image**, lalu pilih gambar tanda tangan.
5. Atur ukuran dan posisinya, kemudian pilih **Save As** agar PDF asli tetap aman.

Catatan: cara ini hanya menempelkan gambar tanda tangan, bukan tanda tangan digital tersertifikasi. Jika ingin, unggah PDF dan gambar tanda tangannya; saya bisa membantu menempatkannya.

## 2026-09-03 17:19:12 WIB — Laporan akhir assistant

Benar—dari gambar terlihat Anda memakai **Microsoft Edge**, bukan Adobe Acrobat. Jadi menu **Fill & Sign** memang tidak tersedia di sana. Maaf, panduan sebelumnya kurang tepat.

Cara melanjutkan:

1. Klik **…** di kanan atas.
2. Pilih **Edit with Acrobat**.
3. Jika Adobe Acrobat terbuka, pilih **Fill & Sign**.
4. Klik **Add signature → Image**.
5. Pilih gambar tanda tangan, atur posisinya, lalu simpan sebagai file baru.

Jika **Edit with Acrobat** tidak bisa digunakan, buka PDF langsung dengan aplikasi **Adobe Acrobat Reader** yang terpasang di komputer. Edge sendiri hanya menyediakan teks dan gambar tangan melalui toolbar, bukan memasukkan file gambar tanda tangan.
