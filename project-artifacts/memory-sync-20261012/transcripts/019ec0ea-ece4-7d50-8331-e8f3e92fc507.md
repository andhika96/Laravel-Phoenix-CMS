## 2026-06-13 19:18:54 WIB — Laporan akhir assistant

Kemungkinan besar **bukan file game yang rusak**. Saat ini dukungan resmi AoE mencatat masalah crash ketika Windows memakai pengaturan bahasa/karakter non-Inggris. Windows berbahasa Indonesia bisa terdampak, dan `Verify integrity` tidak memperbaiki konfigurasi Windows, driver, atau mod.

Coba berurutan:

1. Buka **Settings → Time & language → Language & region → Administrative language settings**.
2. Klik **Change system locale**.
3. Aktifkan **“Beta: Use Unicode UTF-8 for worldwide language support”**.
4. Restart komputer lalu tes game.

Jika masih crash:

- Nonaktifkan semua mod dengan mengganti nama folder:
  `C:\Users\<nama>\Games\Age of Empires 2 DE\<SteamID>\mods`
  menjadi `mods.off`.
- Instal pembaruan Windows dan driver GPU terbaru.
- Instal ulang **Microsoft Visual C++ Redistributable 2022 x64**, lalu restart.
- Tutup sementara Discord Overlay, MSI Afterburner/RivaTuner, GeForce Overlay, dan Xbox Game Bar.
- Tambahkan `AoE2DE_s.exe` ke pengecualian antivirus.
- Jalankan langsung `AoE2DE_s.exe` dari folder instalasi Steam untuk melihat apakah muncul error berbeda.

Jika tetap keluar, periksa crash log terbaru di:

```text
C:\Users\<nama>\My Games\Age of Empires 2 DE\logs
```

Penyebab pastinya biasanya bisa diketahui dari nama modul error di **Event Viewer → Windows Logs → Application**.

Sumber resmi: [Known Issues AoE II: DE](https://support.ageofempires.com/hc/en-us/articles/360049490811-Age-of-Empires-II-Definitive-Edition-Known-Issues-Solutions) dan [panduan crash setelah peluncuran](https://support.ageofempires.com/hc/en-us/articles/360047396372-The-game-crashes-shortly-after-it-launches-or-when-trying-to-start-a-game).
