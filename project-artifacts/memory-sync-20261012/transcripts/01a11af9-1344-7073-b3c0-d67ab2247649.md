```text

├── app\

├── routes\

    ├── GRAPH_REPORT.md
    ├── manifest.json
    ├── metadata-manifest.json
    ├── graph.html
    └── vis-network.min.js
```

Jalankan dari folder utama project:

```powershell

```

Kalau terminal berada di folder lain, lokasi graph bisa disebutkan langsung:

```powershell

```
