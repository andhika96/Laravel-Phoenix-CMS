## 2026-09-23 06:25:55 WIB — Laporan akhir assistant

Betul, **GPT‑6 Sol dan GPT‑6 Luna sudah tercantum di dokumentasi resmi OpenAI, dan harga per tokennya jauh lebih rendah daripada Astra.** Keduanya juga tersedia dalam daftar model yang dikenali lingkungan Codex sesi ini.

Harga dasar API yang saya verifikasi dari **OpenAI Docs**, per 1 juta token:

| Model | Input | Cached input | Output | Perbandingan dengan Astra |
|---|---:|---:|---:|---|
| **GPT‑6 Luna** | $0,10 | $0,01 | $0,50 | **99% lebih murah per token** |
| **GPT‑6 Sol** | $2,00 | $0,20 | $10,00 | **80% lebih murah per token** |
| **GPT‑6 Astra** | $10,00 | $1,00 | $50,00 | Acuan |

Angka tersebut adalah tarif dasar; konteks panjang dan mode pemrosesan dapat mengubah tarif. Sumber: [GPT‑6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT‑6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol), dan [GPT‑6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra).

Untuk pernyataan **“satu tingkat di bawah Astra”**, secara posisi produk arahnya benar: OpenAI menempatkan Astra untuk pekerjaan paling sulit, Sol untuk coding dan alur kerja agentic kompleks, serta Luna untuk tugas terfokus dengan volume tinggi. Tetapi jarak kemampuan tidak selalu berupa satu tingkat yang tetap pada setiap tugas.

Screenshot Anda justru menunjukkan hal menarik: **Sol pada `max` bisa mengungguli Astra pada `low` di beberapa pengujian.**

| Metrik pada screenshot | Sol `max` | Astra `low` |
|---|---:|---:|
| Intelligence Index | **48** | 46 |
| Terminal‑Bench 4.0 | **44%** | 42% |
| SciCode | **58%** | 54% |
| Humanity’s Last Exam | 48% | **49%** |
| GDP.pdf | 25% | **30%** |
| AA‑Omniscience | 27 | **41** |

Ini mendukung kesimpulan bahwa **Sol menarik dari sisi kemampuan terhadap harga**, tetapi belum membuktikan Sol lebih kuat secara keseluruhan: tingkat reasoning yang dibandingkan berbeda, dan screenshot belum memuat hasil Luna.

Ada satu detail biaya yang perlu diperhatikan: pada screenshot, **Cost per Task Sol `max` adalah $1,06, sementara Astra `low` $0,82**. Jadi, dalam pengukuran itu Sol justru sekitar **29% lebih mahal per tugas**, meskipun tarif tokennya 80% lebih murah. Screenshot belum menjelaskan penyebabnya; penggunaan token reasoning dan panjang proses pengerjaan merupakan kemungkinan yang perlu diperiksa dari metodologi benchmark.

Untuk pekerjaan coding Anda, **saya akan menjadikan Sol kandidat utama untuk implementasi sehari-hari, Luna untuk tugas kecil dengan batas jelas, dan Astra untuk diagnosis atau keputusan lintas modul yang sulit**. Itu pembagian awal yang masuk akal berdasarkan posisi resmi model; penghematan sesungguhnya tetap dinilai dari biaya sampai tugas selesai dan hasilnya lolos pengujian. Harga API di atas juga belum berarti kuota langganan Codex akan lebih hemat dengan persentase yang sama.
