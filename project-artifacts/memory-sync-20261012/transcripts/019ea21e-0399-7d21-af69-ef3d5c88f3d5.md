## 2026-06-07 19:48:05 WIB — Laporan akhir assistant

Per **7 Juni 2026**, jawaban jujurnya: **belum ada model gratis yang benar-benar setara 1:1 dengan `GPT-5.4` pada level reasoning `xhigh` untuk coding**.

Sedikit klarifikasi: di OpenAI, nama produk chat-nya adalah **`GPT-5.4 Thinking`** di ChatGPT, sedangkan **`xhigh`** itu level reasoning yang didukung di API, bukan nama model terpisah. Sumber: [OpenAI GPT-5.4 release](https://openai.com/index/introducing-gpt-5-4/) dan [API model doc](https://developers.openai.com/api/docs/models/gpt-5.4).

Kalau yang paling dekat secara praktis:

- **`Claude Sonnet 4.6` Free**: pilihan gratis paling kuat untuk coding via chat. Anthropic menyebut model ini default di plan Free dan naik di coding, long-context, dan computer use.  
  Sumber: [Anthropic Sonnet 4.6](https://www.anthropic.com/news/claude-sonnet-4-6?via=onetts.com)

- **`Gemini 2.5 Pro` / `Gemini CLI` / `Gemini Code Assist`**: terbaik kalau kamu mau workflow coding gratis di terminal/IDE. Google masih mendokumentasikan akses gratis untuk Gemini CLI/Code Assist, dan free tier untuk sebagian penggunaan Gemini.  
  Sumber: [Gemini CLI](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-cli-open-source-ai-agent/), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing?gad_source=1), [Gemini Code Assist overview](https://developers.google.com/gemini-code-assist/docs/overview?hl=en)

- **`GPT-5.4 mini` via ChatGPT Free Thinking**: paling dekat kalau kamu mau “rasa OpenAI”, tapi **masih di bawah `GPT-5.4 xhigh`**. OpenAI sendiri menunjukkan gap performa vs model penuh.  
  Sumber: [GPT-5.4 mini](https://openai.com/index/introducing-gpt-5-4-mini-and-nano/)

- **`Qwen Code` + `Qwen3-Coder`**: opsi open/free yang sangat menarik. Qwen menyebut tool-nya gratis, open-source, dan memberi **1.000 request gratis per hari** via OAuth.  
  Sumber: [Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/blog/thinks-like-a-programmer/), [Qwen3-Coder](https://qwenlm.github.io/blog/qwen3-coder/)

- **`DeepSeek` web/app**: gratis penuh untuk pemakaian umum, cukup kuat untuk coding harian, tapi saya tidak akan bilang setara `GPT-5.4 xhigh` untuk tugas repo besar dan refactor sulit.  
  Sumber: [DeepSeek app](https://api-docs.deepseek.com/news/news250115), [DeepSeek homepage](https://www.deepseek.com/en/)

Kalau harus saya ringkas jadi satu kalimat: **tidak ada yang benar-benar setara gratis**, tapi **yang paling layak dicoba sekarang adalah `Claude Sonnet 4.6 Free` untuk kualitas coding, dan `Gemini CLI/Code Assist` untuk workflow coding gratis di IDE/terminal**.

Kalau mau, saya bisa lanjut bikin **ranking yang lebih spesifik**:
1. terbaik untuk **web/app chat**,  
2. terbaik untuk **VS Code/IDE**, atau  
3. terbaik untuk **self-host/open-source**.
