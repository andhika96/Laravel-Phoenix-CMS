# Manage Event + Event Registration Booking MVP

## Ringkasan

Bangun dalam dua spec berurutan:

1. **Manage Event Content** — modul Event terisolasi dari Article, kategori/status sendiri, occurrence/session, admin CRUD, dan authenticated list/detail.
2. **Event Registration Booking MVP** — registrasi peserta per occurrence dengan kapasitas, waitlist FIFO, cancel, attendance, notifikasi, dan reminder.

Article serta PRD Meeting Room/Asset Booking tetap tidak diubah.

## Perubahan Utama

- Tabel baru melalui `database/migrations` aktif:
  `events`, `event_categories`, `event_occurrences`, `event_booking_settings`, dan `event_registrations`.
- Event menyimpan title, URI unik, content, tags, thumbnail, kategori, publication status, dan visibility public/private.
- Occurrence menyimpan jadwal, timezone, lokasi teks/online URL, lifecycle, registration window, dan capacity wajib.
- Admin UI mengikuti pola Manage Article: Blade + Vue, pagination/filter, category panel, responsive table, thumbnail pipeline path `events`, serta occurrence nested dengan endpoint terpisah.
- Menu legacy `Manage Event` dipertahankan tetapi URL dinormalisasi; `Layout` ditunda/disembunyikan.
- Permission memakai module `manage_event` dengan pola CRUD generik.
- Attendee route memakai `/event`, hanya untuk user login; register/cancel masuk Spec 2.
- Registration unik per account/occurrence, boleh re-register setelah cancel, auto-confirm sampai penuh, lalu waitlist FIFO dan promosi otomatis secara atomik.
- Reminder dan cancel cutoff default 24 jam, dapat dioverride per event. Notifikasi peserta dan admin dikirim melalui notification center serta email after-commit; data peserta tidak dikirim ke public Reverb channel.

Urutan aman:

```bash
# 1. Stage hanya file yang memang ingin masuk
git add <file-atau-folder-terpilih>

# 2. Commit di branch aktif
git commit -m "Implement manage event and article template options"

# 3. Push branch aktif
git push -u origin codex/manage-event-booking
```

Setelah itu, paling aman buat PR dari:

```text
codex/manage-event-booking → main
```

Lalu merge PR ke `main`.

Jangan pakai `git add .` dulu, karena worktree Anda berisi banyak perubahan; pilih file/hunk yang memang sudah siap. Jika ingin merge lokal tanpa PR, commit dan push branch dulu, lalu:

```bash
git switch main
git pull --ff-only origin main
git merge --no-ff codex/manage-event-booking
git push origin main
```
