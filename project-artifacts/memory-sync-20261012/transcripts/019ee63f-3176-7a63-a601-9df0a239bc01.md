## 2026-06-21 01:22:03 WIB — Laporan akhir assistant

Bisa, tapi ada batas teknis penting.

Untuk **membangun ulang maksimal 1 barracks, 1 archery range, 1 stable, 1 blacksmith, dan 1 TC**, itu bisa dibuat. Rule-nya tinggal menjaga `building-type-count-total < 1`, lalu `can-build`, lalu queue build.

Yang perlu hati-hati adalah bagian **“tepat di titik bangunan yang sudah hancur”**. Script PER tidak otomatis tahu bekas footprint bangunan yang hancur secara presisi. Ada 3 pendekatan:

1. **Paling aman untuk mini AI umum:** rebuild 1 bangunan per jenis di area kota AI, bukan dijamin titik lama.
2. **Paling presisi untuk scenario:** kita hardcode koordinat slot bangunan di file config mini AI. Kalau bangunan hancur, AI pakai `up-set-target-point` + `up-build place-point` ke koordinat itu.
3. **Semi-manual:** player flare titik rebuild, lalu AI membangun di flare. Ini presisi, tapi tidak otomatis.

Rekomendasi saya untuk kebutuhan Anda: **pakai pendekatan 2**. Mini AI ini memang untuk scenario ally di luar markas Player 1, jadi kita bisa buat file config slot koordinat. Nanti default-nya bisa saya isi placeholder, lalu kalau Anda beri koordinat atau kita ambil dari scenario, AI akan rebuild tepat di slot itu.

Desain yang saya usulkan:
- Nama package baru: `ArunikaAI_v4_Mini`
- Villager hidup maksimal target: `8`
- Building cap: `1` per `town-center`, `barracks`, `archery-range`, `stable`, `blacksmith`
- Army cap: `10 infantry`, `10 archer`, `10 cavalry`
- Research otomatis hanya dari TC, barracks, archery range, stable, blacksmith
- Tidak ada wave attack besar, tidak build wall/tower/castle/market/monastery/siege/dock
- Rebuild bangunan utama memakai titik koordinat config jika tersedia

Kalau desain ini Anda setujui, saya lanjut eksekusi: buat file baru, backup dulu, audit, lalu sync ke `D:\New AI Script AoE II DE` dan folder game AoE2DE.
