## 2026-06-28 03:44:01 WIB — Laporan akhir assistant

Root cause paling kuat: server tidak punya `.env` berisi credential Intibis yang valid, atau nilainya kosong/beda.

Buktinya:
- Commit audit terakhir memindahkan credential OTP dari hardcoded di [promotion.php](E:/Apps/Laragon/www/newmg/modules/promotion/promotion.php:748) ke `INTIBIS_USERNAME` dan `INTIBIS_PASSWORD`.
- `.env` masuk `.gitignore`, jadi saat server hanya `git pull`, isi `.env` tidak ikut terkirim.
- `.env.example` memang punya key `INTIBIS_USERNAME` dan `INTIBIS_PASSWORD`, tapi kosong.
- Local laptop punya `.env` dan nilainya match dengan credential lama yang dulu hardcoded, makanya di Laragon lokal OTP masih bisa jalan.
- Pesan merah di screenshot berasal dari branch gagal di [promotion.php](E:/Apps/Laragon/www/newmg/modules/promotion/promotion.php:834), yaitu saat API SMS tidak return `1701 Success`.

Yang perlu dicek/benahi di server: buat atau update file `.env` di root project server dengan nilai Intibis yang sama seperti `.env` lokal, terutama:

```env
INTIBIS_USERNAME=...
INTIBIS_PASSWORD=...
```

Setelah itu reload PHP/web server kalau pakai PHP-FPM/opcache. Saya belum mengubah file apa pun. Verifikasi yang saya jalankan: `php -l` untuk `modules/promotion/promotion.php`, `index.php`, dan `application/common/function.php`, semuanya no syntax errors; worktree juga clean.

Catatan dari Google Drive memory juga mengonfirmasi audit keamanan memang memindahkan credential `modules/promotion/promotion.php` ke `.env`: [project_newmg_security_fix.md](https://docs.google.com/document/d/1KHIvu6YgTWOzDiOWP30X55yVmGGV3wlTDa39d3pgAJo).
