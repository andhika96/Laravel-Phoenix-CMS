## 2026-09-01 21:44:43 WIB — Laporan akhir assistant

Kalau maksudnya membuat blok tanda tangan di kiri dan kanan, cara paling rapi di Word adalah memakai tabel:

1. Pilih **Insert → Table → 1×2**.
2. Masukkan blok kiri ke kolom pertama.
3. Copy teks **“Hormat saya,”**, gambar tanda tangan, dan nama ke kolom kedua.
4. Klik tabel → **Table Design → Borders → No Border**.
5. Atur lebar kedua kolom dan posisi teks sesuai kebutuhan.

Sebaiknya tanda tangan diatur **Wrap Text → In Line with Text** agar tidak mudah bergeser. Jangan gunakan banyak spasi karena posisi bisa berubah saat dokumen dicetak.

## 2026-09-01 21:46:47 WIB — Laporan akhir assistant

Bisa. Posisi teksnya kemungkinan diatur **vertically centered** atau ada jarak paragraf.

1. Klik di dalam sel yang berisi **“Hormat saya,”**.
2. Buka tab **Table Layout**.
3. Pada bagian **Alignment**, pilih ikon **Align Top Left**.
4. Blok teksnya → **Home → Paragraph**:
   - **Before: 0 pt**
   - **After: 0 pt**
   - **Line spacing: Single**
5. Jika masih turun, tekan **Ctrl + Shift + 8** untuk menampilkan tanda ¶, lalu hapus Enter kosong sebelum “Hormat saya,”.
6. Bila perlu, pilih **Table Layout → Cell Margins**, lalu kecilkan **Top** menjadi 0 atau 0,05 cm.

Jangan menaikkan dengan spasi atau banyak Enter karena posisi bisa berubah saat dicetak.
