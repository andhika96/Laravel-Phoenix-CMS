## Kontrak options yang dinormalisasi

`ArticleTemplateOptions::archive('editorial-journal', ...)` menambahkan blok khusus berikut tanpa memengaruhi template lain:

```php
'editorial_journal' => [
    'lead_grid' => [
        'divider' => [
            'enabled' => true,
        ],
        'spacing' => [
            'with_divider' => '2rem',
            'without_divider' => '2rem',
        ],
    ],
    'thumbnail' => [
        'edge_to_edge' => false,
    ],
    'card' => [
        'border' => [
            'enabled' => true,
            'type' => 'solid',
            'width' => '1px',
            'color' => '#e6e9ef',
            'radius' => '0.9rem',
        ],
        'background' => [
            'type' => 'color',
            'color' => '#ffffff',
            'image' => '',
        ],
        'height' => [
            'mode' => 'auto',
            'desktop' => '22rem',
            'tablet' => '22rem',
            'mobile' => '22rem',
        ],
    ],
    'read_more' => [
        'enabled' => false,
        'position' => 'left',
        'icon' => 'fas fa-arrow-right',
    ],
],
```

Normalisasi dan fallback:

- `divider.enabled`: boolean.
- `spacing`: memakai unit existing `px`, `em`, `rem`, `%`, `pt`.
- `thumbnail.edge_to_edge`: boolean.
- `border.type`: `solid`, `double`, `dotted`, `dashed`, `groove`.
- `border.width`: memakai border unit existing `px`, `em`, `rem`, `pt`.
- `border.radius`: memakai radius four-corner existing.
- `background.type`: `color` atau `image`.
- `background.color`: hanya warna yang lolos validator existing.
- `background.image`: hanya URL `http://`, `https://`, atau relative single-slash URL; menolak `javascript:`, `data:`, `vbscript:`, protocol-relative URL, quote, dan URL yang dapat merusak CSS.
- `height.mode`: `auto` atau `fixed`.
- `height.desktop/tablet/mobile`: dimension value yang aman.
- `read_more.position`: `left`, `center`, `right`.
- `read_more.icon`: allowlist Font Awesome lokal:
  `fas fa-arrow-right`, `fas fa-chevron-right`, `fas fa-angle-right`.
