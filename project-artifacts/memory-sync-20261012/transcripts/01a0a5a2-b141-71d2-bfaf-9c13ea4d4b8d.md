## Cara upload di phpMyAdmin VPS

1. Siapkan backup database VPS terlebih dahulu.
2. Pilih database **`itbumdev`**, lalu tab **Import**.
3. Pilih **ZIP final** di atas, dengan format **SQL**.
4. Jika ada opsi **Partial import / Allow interruption**, **nonaktifkan**. Proses ini harus selesai dalam satu koneksi karena menggunakan tabel sementara.
5. Jalankan import. Jika muncul error, hentikan; jangan paksa melanjutkan.
6. Periksa hasil terakhir:

```text
import_status    = COMPLETED
source_rows      = 9585
inserted_rows    = jumlah pokok baru
skipped_existing = jumlah pokok yang sudah ada
```

Jumlah `inserted_rows + skipped_existing` harus **9.585**.
