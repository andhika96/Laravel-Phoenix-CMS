Ketiganya tersedia untuk **Minimal Reading List, Editorial Journal, Mosaic Magazine, Mosaic Classic, dan Balanced Card Grid**. Pilihannya berasal dari [panel settings pagination yang sama](/D:/Laragon/www/laravel-13-phoenix/resources/views/manage_article/templates/partials/options-styling.blade.php:78), dan kelima template memakai partial pagination bersama.

**Namun, tampilannya saat ini belum sepenuhnya seragam meskipun nilai settings-nya sama.** Ini perbandingan menggunakan CSS source aktif:

![Perbandingan tiga model pagination pada lima template](/D:/Laragon/www/laravel-13-phoenix/project-artifacts/mockups/20261009_minimal-reading-list-revamp/pagination-audit/comparison.png)

[Buka perbandingan di browser](http://127.0.0.1:8774/pagination-audit/index.html).

Perbedaan yang sudah terukur:

- **Ukuran tombol:** Minimal Reading List memakai tinggi **44 px**, sedangkan empat template lainnya sekitar **37,6 px** pada root font 16 px.
- **Radius halaman aktif:** pada Classic Boxed dan Soft Highlight, Minimal Reading List masih menghasilkan sudut **0 px**, sedangkan template lainnya mengikuti setting radius—**7,2 px** dalam pengujian ini.
- **Footer frame:** Minimal Reading List memaksanya menjadi garis atas dengan radius 0, sementara template lain menampilkan frame berborder dan bersudut membulat.
- **Blade dan Vue:** padding horizontal default Minimal Reading List berubah dari **0 px pada Blade** menjadi **16 px pada Vue**. Penyebabnya terkonfirmasi pada rule padding Vue yang menggunakan `!important`.

Penyebab utama berada di [override CSS pagination khusus Minimal Reading List](/D:/Laragon/www/laravel-13-phoenix/public/assets/css/article/article-frontend-2026.css:2060), yang masih memengaruhi ketiga model bersama.

Untuk revamp berikutnya, **ketiga model tetap menjadi pilihan di settings, dan setiap model memiliki standar visual yang sama pada semua archive template**: ukuran dan spacing dasar, state normal/hover/active/disabled, radius sesuai model/settings, serta footer frame dan hasil Blade/Vue yang konsisten. Struktur komponen bersama yang diperlukan sudah tersedia.

Pemeriksaan mencakup **30 hasil render CSS komponen**—5 template × 3 model × class renderer Blade/Vue. Source aplikasi dan settings tersimpan belum diubah. Detail file yang dibaca, Graphify, backup skrip audit, hasil pengukuran, dan batas verifikasinya ada di [laporan audit](/D:/Laragon/www/laravel-13-phoenix/project-artifacts/mockups/20261009_minimal-reading-list-revamp/pagination-audit/README.md).
