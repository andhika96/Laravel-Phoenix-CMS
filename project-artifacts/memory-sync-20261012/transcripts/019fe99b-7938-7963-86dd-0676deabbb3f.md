- Feature branch 44 commit di depan `main`

Sebelum melanjutkan: branch tersebut membawa 190 file `.bak_*`. Jika itu tidak boleh masuk `main`, jangan jalankan langkah berikut dahulu.

Jika seluruh isinya memang ingin dimasukkan ke `main`, sekaligus menghapus feature branch dari GitHub dan Git Bash, jalankan satu per satu:

```bash
git switch main
git merge --ff-only feat/pagebuilder-v23-isolation
git push origin main
```

Pastikan push ke `main` berhasil. Setelah itu hapus branch GitHub:

```bash
git push origin --delete feat/pagebuilder-v23-isolation
```

Kemudian hapus branch lokal:

```bash
git branch -d feat/pagebuilder-v23-isolation
```

Verifikasi akhirnya:

```bash
git status
git branch -vv
```

Untuk pekerjaan berikutnya yang memang ingin langsung masuk `main`, pastikan pindah ke `main` sebelum membuat commit:

```bash
git switch main
git pull --ff-only origin main
```

Setelah edit dan commit:

