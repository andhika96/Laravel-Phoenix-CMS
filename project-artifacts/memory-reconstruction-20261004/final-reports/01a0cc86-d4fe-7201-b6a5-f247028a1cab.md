## 2026-09-23T04:41:09.907Z

Maksudnya, pada **17 halaman list reguler** ada dua pengaman agar tidak mengirim permintaan data berulang saat Anda kembali ke tab:

- Jika data list baru selesai dimuat **kurang dari 1 detik lalu**, halaman tidak meminta data lagi. Contoh: list selesai dimuat, Anda pindah tab sebentar selama 0,5 detik, lalu kembali. Data yang baru dimuat tetap ditampilkan.
- Jika permintaan data **masih berjalan**, halaman menunggu hasil permintaan itu dan tidak membuat permintaan kedua.

Jika Anda kembali setelah lebih dari 1 detik sejak pemuatan terakhir selesai, halaman akan langsung meminta ulang data list. Jadi fitur auto refresh memang terpasang; kalimat saya sebelumnya hanya menjelaskan pengecualian singkat untuk mencegah permintaan ganda.
