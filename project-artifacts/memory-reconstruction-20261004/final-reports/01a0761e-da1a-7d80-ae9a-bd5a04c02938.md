Desain implementasi yang saya usulkan:

### 1. Divider antara featured article dan article grid

Tambahkan setting khusus Editorial Journal:

```text
Show divider: On / Off
```

Default:

```text
On
Border: 1px solid #e6e9ef
```

Perilaku:

- Aktif: tampilkan garis pemisah seperti desain sekarang.
- Nonaktif: garis dihapus tanpa mengubah struktur lead dan grid.
- Tidak menambah opsi border type/color untuk divider karena permintaan Anda hanya membutuhkan toggle dan current design sudah memiliki bentuk divider yang tepat.

### 2. Thumbnail inset atau edge-to-edge

Tambahkan:

```text
Thumbnail position:
- Inset inside card
- Edge-to-edge
```

Default:

```text
Inset inside card
```

Perilaku:

- `Inset inside card`: mempertahankan tampilan saat ini, thumbnail berada di dalam padding card.
- `Edge-to-edge`: thumbnail menempel ke batas luar card, sementara content card tetap memiliki padding.
- Card tetap memakai `overflow: hidden` agar radius luar dan thumbnail tetap rapi.

### 3. Card border customization

Tambahkan grup:

```text
Card border: On / Off
```

Jika aktif:

```text
Border type
Border width
Border color
Border radius
```

Default yang mempertahankan desain saat ini:

```text
Enabled: true
Type: solid
Width: 1px
Color: #e6e9ef
Radius: 0.9rem
```

`Border radius` akan menggunakan pola four-corner control yang sama seperti Padding, Margin, dan Pagination button radius.

### 4. Card background color/image

Tambahkan grup:

```text
Card background:
- Color
- Image
```

Default:

```text
Mode: Color
Color: #ffffff
Image: kosong
```

Jika memilih `Image`:

- Tampilkan media picker CKFinder.
- Tampilkan thumbnail preview image.
- Tambahkan tombol Change Image dan Remove Image.
- Background image memakai `cover`, `center center`, dan `no-repeat`.
- Background color tetap menjadi fallback.
- URL akan dinormalisasi secara fail-closed sebelum dipakai renderer.

Tidak akan menambah external URL field karena Anda meminta integrasi CKFinder seperti Page Builder dan itu sudah mencukupi.

### 5. Spacing antara lead dan grid

Tambahkan dua setting terpisah:

```text
Spacing with divider
Spacing without divider
```

Keduanya menggunakan unit control existing:

```text
px, em, rem, %, pt
```

Default awal:

```text
With divider: 2rem
Without divider: 2rem
```

Renderer memilih nilai berdasarkan kondisi divider aktif/nonaktif. Dengan begitu jarak dapat dibuat berbeda tanpa mengubah markup atau memakai margin hard-coded yang tidak bisa dikustomisasi.

### 6. Optional Read More button

Saya menyarankan setting ini diterapkan pada article grid card, sementara link `Read article` pada featured article tetap dipertahankan sebagai bagian dari desain existing.

Setting:

```text
Show Read More: On / Off
Position:
- Left
- Center
- Right

Icon:
- Arrow right
- Chevron right
- Angle right
```

Default untuk menjaga tampilan saat ini:

```text
Show Read More: Off
Position: Left
Icon: fas fa-arrow-right
```

Jika diaktifkan, setiap card grid mendapatkan link button dengan posisi yang dipilih. Style tetap menggunakan bahasa visual existing `article-text-link`, bukan tombol besar Bootstrap yang akan membuat template berubah terlalu jauh.

### 7. Card height pada article grid

Tambahkan:

```text
Card height:
- Auto
- Fixed
```

Default:

```text
Auto
```

Jika memilih `Fixed`, saya menyarankan tinggi dibuat responsive per device:

```text
Desktop card height
Tablet card height
Mobile card height
```

Alasannya, tinggi fixed yang aman di desktop bisa terlalu besar atau terlalu kecil di mobile. Mode Auto tetap mempertahankan perilaku current grid dan flex-column card.

### 8. Default thumbnail height

Untuk Editorial Journal saja, default thumbnail akan diubah menjadi:

```text
12.5rem
```

Template lain tidak ikut berubah:

- Minimal Reading List tetap `9.3rem`.
- Template archive lain tetap memakai default masing-masing.
- Scope perubahan hanya `editorial-journal`.

Urutan implementasi setelah desain ini disetujui:

1. Tambahkan test normalizer untuk seluruh default dan sanitasi setting Editorial Journal.
2. Tambahkan test render untuk divider, edge-to-edge thumbnail, card border/background, read more, card height, dan `12.5rem`.

5. Hubungkan Blade preview dan public renderer dengan opsi yang sama.

Dua keputusan yang perlu dikunci sebelum saya membuat spec dan plan implementasi:
