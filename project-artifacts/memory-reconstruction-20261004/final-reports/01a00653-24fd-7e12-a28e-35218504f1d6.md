## 2026-08-16T01:12:27.913Z

Berarti sudah terkonfirmasi: **fokus input benar-benar hilang setelah klik pertama**.

Kandidat terkuatnya adalah handler global `focusin` di `app.js`. Saat input pertama difokuskan, handler menjadwalkan scroll panel melalui `requestAnimationFrame`. Di Firefox, posisi input dapat bergeser sebelum rangkaian `mouseup/click` selesai sehingga fokus terlepas. Klik kedua berhasil karena posisi panel sudah stabil.

Langkah berikutnya sebaiknya satu perubahan terisolasi:

- nonaktifkan auto-scroll `focusin`;
- jangan rollback semua optimasi sebelumnya;
- tambahkan regression test fokus awal;
- verifikasi build/test;
- lalu Anda coba lagi di Firefox.

Anda tidak perlu melakukan tes tambahan. Jika setuju, balas **“lanjut perbaiki focusin”**, lalu saya kerjakan dengan backup terlebih dahulu.
