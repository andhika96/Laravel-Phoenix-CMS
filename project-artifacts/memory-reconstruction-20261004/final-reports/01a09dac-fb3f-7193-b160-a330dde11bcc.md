Ya, benar. Command tersebut memang khusus untuk menjalankan proses background pada fitur:

- Import **Batas Ancak**
- Import **Pokok**

Urutan yang disarankan di localhost:

1. Jalankan aplikasi Laravel pada terminal pertama, jika belum memakai Apache/Nginx Laragon:

```powershell
cd D:\Laragon\www\laravel-13-cms-bum
php artisan serve
```

2. Buka terminal Laragon kedua dan jalankan worker GIS:

```powershell
cd D:\Laragon\www\laravel-13-cms-bum
php artisan queue:work database --queue=gis-imports
```

3. Biarkan terminal worker tetap terbuka.

4. Setelah itu, buka fitur Import Batas Ancak atau Import Pokok dan lakukan upload ZIP/SHP seperti biasa.

Sebenarnya worker tidak wajib dijalankan lebih dahulu. Jika Anda mengunggah file ketika worker belum aktif:

- data import akan masuk ke tabel queue;
- status import kemungkinan tetap `queued`;
- proses validasi tidak berjalan;
- setelah command worker dijalankan, job yang tertunda akan langsung diproses.

Namun, untuk penggunaan normalannya memang lebih nyaman menjalankan worker terlebih dahulu agar setelah upload proses import langsung bergerak.

Worker ini juga harus tetap aktif ketika Anda menekan aksi lanjutan seperti:

- `Commit`
- `Retry`
- melanjutkan validasi atau publikasi batch

Jika terminal worker ditutup atau komputer direstart, jalankan kembali:

```powershell
php artisan queue:work database --queue=gis-imports
```

Anda tidak perlu menjalankan dua worker terpisah untuk Pokok dan Batas Ancak. **Satu command tersebut menangani keduanya.** Jangan menjalankan `php artisan queue:work` tanpa `--queue=gis-imports` jika tujuannya hanya memproses import GIS, karena tanpa filter itu worker dapat ikut mengambil job aplikasi lain dari queue default.
