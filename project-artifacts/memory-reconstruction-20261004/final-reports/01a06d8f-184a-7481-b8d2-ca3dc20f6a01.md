- `.article-template-options-settings` sekarang menjadi boundary dengan `overflow: hidden`.
- `.article-template-options-panel` sekarang memakai:
  - `height: auto`;
  - `flex: 1 1 0%`;
  - `min-height: 0`;
  - `max-height: 100%`;
  - `overflow-y: auto`;
  - `overflow-x: hidden`.
- Tidak ada body scroll lock.
- Tidak ada `position: fixed` workaround.
- Tidak ada scroll-jacking.
