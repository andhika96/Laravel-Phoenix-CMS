## 2026-05-27T05:56:46.627Z

Betul, karena di Elementor memang **sengaja ada dua mode layout container**: `Flexbox` dan `Grid`.

Kenapa `Grid` tetap ada di demo:
1. `Grid` dipakai untuk layout simetris baris-kolom yang cepat di-setup.
2. `Flexbox` dipakai untuk layout linear/asimetris yang lebih bebas.
3. Mereka tetap menampilkan opsi Grid sebagai entry point cepat, meski di panel setting bisa switch tipe container.

Ini konsisten dengan dokumentasi resmi Elementor:
- [What is a Flexbox Container? (Last update: January 10, 2024)](https://elementor.com/help/using-containers/)
- [Layout options using a grid container (Last update: January 19, 2025)](https://elementor.com/help/grid-container-layout-options/)
- [Create a Grid container (Last update: August 31, 2025)](https://elementor.com/help/create-a-grid-container/)

Jadi keputusan produk kita ada 2 opsi:
1. Tetap ada `Grid` di sidebar (mirip Elementor), tapi samakan schema/settings dengan container-grid agar tidak beda perilaku.
2. Sembunyikan `Grid` sidebar dan pakai hanya `Container` + preset flex/grid (lebih sederhana).
