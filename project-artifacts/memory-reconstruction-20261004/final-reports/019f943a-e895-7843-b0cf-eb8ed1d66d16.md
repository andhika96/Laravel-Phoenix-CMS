## 2026-07-24T13:19:37.190Z

Saya melihat peringatan untuk SSD Portable `Andhika G (E:)`. Jangan klik **“Scan the drive now and fix it”** atau menulis file baru dulu.

Pemeriksaan aman yang saya jalankan tidak selesai dalam 64 detik, dan sesi otomatis ini tidak dapat mengakses volume `E:` secara langsung. Jadi saya tidak akan menjalankan perbaikan yang dapat mengubah struktur file tanpa memastikan data aman.

Lakukan ini dulu:

1. Jika drive masih bisa dibuka, salin file paling penting ke disk lain.
2. Lepas-pasang SSD dengan aman, lalu coba kabel atau port USB lain—hindari USB hub.
3. Setelah data penting aman, buka PowerShell **Administrator** dan jalankan:

```powershell
chkdsk E: /f
```

`/f` akan memperbaiki kesalahan file system; jangan cabut SSD selama proses berjalan. Jangan pakai `/r` dulu karena pemindaian SSD bisa jauh lebih lama dan belum diperlukan untuk peringatan ini. Microsoft menjelaskan bahwa `chkdsk` tanpa parameter hanya memeriksa status, sedangkan `/f` melakukan perbaikan. [Dokumentasi CHKDSK Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)

Jika `chkdsk E: /f` macet, drive putus-nyambung, atau gagal terbaca, hentikan upaya perbaikan berulang dan utamakan penyelamatan data—itu lebih mengarah ke masalah kabel, casing USB, atau SSD-nya.
