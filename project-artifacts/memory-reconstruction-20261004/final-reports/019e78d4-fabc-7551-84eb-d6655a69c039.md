## 2026-05-30T12:28:35.066Z

Benar, dari menu yang ada di screenshot itu memang **tidak ada opsi “change folder”**.

Per tampilan Codex saat ini (30 Mei 2026), project diikat ke folder saat project dibuat. Jadi:
- `Rename project` hanya ganti nama project
- kalau mau ganti folder, caranya buat **project baru** yang menunjuk ke folder target

Langkah praktis:
1. Klik `New thread` atau `Add project`
2. Pilih folder/repo yang baru
3. Lanjut kerja di project baru (project lama bisa tetap disimpan atau di-`Remove` dari daftar)
