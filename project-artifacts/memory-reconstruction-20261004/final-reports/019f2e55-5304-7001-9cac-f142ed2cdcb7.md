Iya, benar.

Sekarang konsepnya tiap mode device punya nilai sendiri:

`Desktop`, `Tablet Portrait`, dan `Mobile Portrait` menyimpan setting masing-masing untuk control seperti `Header radius`, `Header padding`, `Link radius`, dan `Container margin`.

Jadi kalau kamu pilih `Tablet Portrait` di `Link radius` lalu ubah nilainya, nilai untuk `Desktop` dan `Mobile Portrait` tidak ikut berubah. Tapi mode dropdown-nya sendiri dibuat global/sinkron: kalau kamu ganti dari Desktop ke Tablet di satu form, form responsive lain ikut pindah ke view Tablet juga, seperti pola multiview di page builder.

Singkatnya:

- pilihan device/view = sinkron global antar form
- nilai setting tiap device = tersimpan masing-masing
- preview mengikuti device aktif dan nilai device tersebut
