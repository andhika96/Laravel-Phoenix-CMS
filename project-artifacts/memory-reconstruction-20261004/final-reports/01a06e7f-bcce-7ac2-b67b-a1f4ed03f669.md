### Tampilan opsi setting

| Kontrol | Rencana UI/UX |
|---|---|
| **Text input** | Rounded mengikuti CMS, border tipis, label di atas, tinggi konsisten. Saat fokus ada ring warna tema yang jelas. |
| **Textarea** | Gaya sama dengan input, minimal tiga baris, hanya bisa diperbesar vertikal agar layout tidak rusak. |
| **Form select** | Field rounded, teks pilihan di kiri, chevron di kanan. Digunakan untuk Image fit, Display mode, Stay/Sticky, Heading level, dan lainnya. |
| **Switch / toggle** | Untuk Show/Hide atau Enable/Disable. Label di kiri, switch di kanan; ON warna tema, OFF netral. Kontrol turunannya muncul atau aktif sesuai toggle. |
| **Checkbox** | Untuk pilihan independen yang bisa dipilih lebih dari satu—**hanya jika memang diperlukan opsi existing**. Kotak kecil rounded dengan checkmark, bukan pengganti semua switch. |
| **Radio** | Untuk satu pilihan dalam satu kelompok. Alignment Left/Center/Right ditampilkan sebagai **segmented control rounded**, dengan satu pilihan aktif. |
| **Angka + unit** | Satu field gabungan: nilai angka di kiri, unit seperti `px`/`rem` di kanan, divider halus, sudut luar rounded. |
| **Padding / margin** | Empat field Top/Right/Bottom/Left, tombol Link/Unlink, dan pilihan perangkat. Pada layar sempit menjadi grid 2×2. |
| **Color picker** | Swatch warna + nilai warna dalam satu field, tetap memakai Coloris lokal yang sudah ada. |
| **Tombol aksi** | Cancel abu-abu dan Apply changes mengikuti warna tema CMS, dengan radius tombol CMS—berbeda dari radius luar modal. |

**Untuk select:** field tertutupnya akan mengikuti desain CMS, tetapi popup daftar pilihannya tetap native browser. Jadi tampilannya ketika terbuka bisa berbeda antara Windows/browser. Tidak perlu menambah library dropdown hanya untuk beberapa pilihan.

### Klik Customize membuka apa?

**Tetap di modal yang sama; hanya isi panel tengah yang berganti.**

- Klik **Archive toolbar** → panel tengah berisi Search, alignment, Category filter, dan filter style.
- Klik **Reading list sidebar** → panel tengah berisi Show sidebar, Categories, Popular Posts, serta posisi Stay/Sticky.
- Panel kiri tetap terlihat, preview kanan tetap berada di tempatnya.
- Perubahan sementara tidak hilang saat berpindah kategori, dan perpindahan kategori saja tidak perlu me-reload preview.

Ada penyesuaian terhadap gambar: source aktif juga memiliki **Post list spacing**, serta **Grid columns** pada template tertentu. Plan mempertahankan keduanya, bukan membatasi menu menjadi tujuh seperti mockup.

### Apakah modal full width?

**Desktop: hampir full width, tetapi tidak menempel ke tepi layar.** Usulan lebarnya maksimal **1.680px**, dengan jarak minimal **24px di kiri dan kanan**, agar bentuk rounded tetap terlihat.

- **Desktop lebar:** tiga kolom—Customize, Settings, Live preview.
- **Tablet / laptop sempit:** Customize tetap tersedia; area konten memakai pilihan **Settings / Preview**, supaya form tidak terjepit.
- **Mobile:** pemilih kategori menjadi dropdown dan Settings/Preview ditampilkan bergantian.

Live preview mengikuti perubahan sementara tanpa menyimpan database. **Apply changes** memasukkan perubahan ke draft halaman; **Save Template** tetap menjadi langkah penyimpanan permanen.
