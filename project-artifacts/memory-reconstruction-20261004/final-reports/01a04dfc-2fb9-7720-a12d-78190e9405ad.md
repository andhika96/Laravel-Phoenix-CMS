## 2026-08-30T11:58:53.951Z

Menurut saya itu solusi yang paling tepat. `max-width` jangan hardcoded tanpa kontrol.

Saya sarankan menambahkan di `Style → Grid`:

- **Content Width**
  - `Max Width`
  - `Full Width (100%)`
- **Max Width**
  - range + numeric input + unit selector
  - responsive per desktop/tablet/mobile
  - tampil hanya saat mode `Max Width`

Default tetap `Max Width: 1636px` agar tampilan screenshot sekarang tidak berubah. Jika memilih `Full Width`, header dan cards sama-sama mengikuti lebar 100% dari area widget, sehingga sejajar dengan Event Highlight.

Setting ini sebaiknya berlaku bersamaan untuk header dan cards agar tidak terjadi pergeseran alignment. Menurut saya nama `Content Width` lebih tepat daripada `Grid Max Width` karena mengatur seluruh area internal widget.

Belum ada source yang diubah pada turn ini.
