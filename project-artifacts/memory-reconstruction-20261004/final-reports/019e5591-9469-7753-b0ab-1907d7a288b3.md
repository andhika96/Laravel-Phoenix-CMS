## 2026-05-23T16:07:43.522Z

Poin nomor 1 maksudnya kita “bersihin jalur masuk” page builder dulu supaya tidak membingungkan saat development lanjut.

Saat ini ada 3 jalur yang mirip:
- `pagebuilder` (lama/monolith)
- `pagebuilder-rewrite` (sebagian tidak lengkap)
- `pagebuilder-elementor` (yang paling baru dan sesuai sesi kemarin)

Yang saya maksud dirapikan:
1. Tetapkan `pagebuilder-elementor` sebagai jalur utama yang dipakai.
2. Jalur `pagebuilder-rewrite` yang setengah jadi kita nonaktifkan dulu (atau dibatasi), biar tidak kepanggil error.
3. Pastikan link/menu internal mengarah ke jalur elementor, bukan ke jalur lama/antara.
4. Builder lama tetap disimpan, tidak dihapus, hanya tidak dijadikan default.

Jadi ini bukan hapus fitur, tapi lebih ke mengurangi risiko salah route dan bikin alur kerja kita fokus ke modul yang benar.

## 2026-05-23T16:21:42.678Z

Iya, **bisa**. Di Elementor Flexbox, container memang bisa di-nest ke dalam container lain (parent → child container).  
Di dokumentasi resmi mereka juga dijelaskan kamu bisa drag container ke dalam existing container: [Create a Flexbox container](https://elementor.com/help/how-do-i-create-a-container/).

Catatan kecil:
- `Container` nested: sesuai Elementor.
- `Container Fluid`: ini bukan nama widget native Elementor, lebih ke versi custom di builder kamu. Jadi behavior boleh sama, tapi secara “rasa Elementor” biasanya itu cukup jadi **setting lebar/layout** di container, bukan tipe struktur berbeda.

## 2026-05-23T16:52:48.922Z

Trace bug-nya ketemu, dan sudah saya patch.

Penyebab utama:
1. Setelah kita tambah slot `footer` (`+ Add`) di dalam `draggable`, elemen footer ikut terbaca sebagai item sortable.
2. Akibatnya saat drag `Row Grid` ke container kosong, target drop jadi sering dianggap tidak valid (muncul ikon merah `not-allowed`).
3. Tombol/teks di empty state juga sempat “menangkap” pointer saat drag.

Perbaikan yang saya terapkan:
1. Batasi elemen draggable hanya node builder dengan `draggable=".pb-node"` di semua dropzone root/container/column.
2. Saat mode drag aktif, empty footer dibuat `pointer-events: none` supaya drop tetap terbaca ke zone.
