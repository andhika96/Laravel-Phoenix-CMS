
4. [index.php](/D:/Laragon/www/newmg/index.php:57) memakai `production` sebagai lingkungan default dan menyembunyikan error. Karena error terjadi saat header dirender, proses pembuatan halaman dapat terhenti tanpa pesan error terlihat. Template juga memanggil renderer desktop dan mobile di [page.tpl.php](/D:/Laragon/www/newmg/themes/default/page.tpl.php:353).

## 2026-10-02T03:12:32.032Z

Bisa. Karena baris menu tersebut **sudah ada**, gunakan **`UPDATE`**, supaya tidak menambah data duplikat. Query ini mengganti **ikon MGS5 EV saja** dengan path dari backup lama; nama, link, urutan, dan menu lain tetap memakai data terbaru.

**Pilih database NewMG yang dipakai website di phpMyAdmin**, lalu copy-paste query berikut:

```sql
-- Ganti menu_icon MGS5 EV dari array kosong menjadi path backup lama.
UPDATE `ml_dropdown_menu`
SET `menu_vars` = JSON_SET(
    `menu_vars`,
    '$[0].menu_icon',
    'contents/userfiles/menu_icon/202601/a7944e889e259f14dd067c680de5912c.png'
)
WHERE `id` = 2
  AND `dropdown_id` = 2
  AND JSON_UNQUOTE(
      JSON_EXTRACT(`menu_vars`, '$[0].menu_name')
  ) = 'MGS5 EV'
  AND JSON_TYPE(
      JSON_EXTRACT(`menu_vars`, '$[0].menu_icon')
  ) = 'ARRAY'
  AND JSON_LENGTH(
      JSON_EXTRACT(`menu_vars`, '$[0].menu_icon')
  ) = 0;

-- Periksa hasilnya.
SELECT
    `id`,
    `dropdown_id`,
    JSON_UNQUOTE(
        JSON_EXTRACT(`menu_vars`, '$[0].menu_name')
    ) AS `menu_name`,
    JSON_TYPE(
        JSON_EXTRACT(`menu_vars`, '$[0].menu_icon')
    ) AS `menu_icon_type`,
    JSON_UNQUOTE(
        JSON_EXTRACT(`menu_vars`, '$[0].menu_icon')
    ) AS `menu_icon`
FROM `ml_dropdown_menu`
WHERE `id` = 2
  AND `dropdown_id` = 2;
```

Hasil yang diharapkan: **1 baris berubah**, `menu_name` bernilai **MGS5 EV**, dan `menu_icon_type` menjadi **STRING**. Setelah itu, reload website.

**Ya, query tadi bisa langsung dijalankan melalui HeidiSQL**, asalkan database yang dipilih adalah **database NewMG yang digunakan website**. Query tersebut adalah **`UPDATE`**, bukan `INSERT`: hanya mengganti nilai ikon MGS5 EV pada baris yang sesuai.

Agar Anda bisa memeriksa hasilnya **sebelum menyimpan perubahan**, gunakan transaksi berikut. Tabel pada dump Anda menggunakan **InnoDB**, sehingga mendukung `COMMIT` dan `ROLLBACK`.

1. Pilih database NewMG di panel kiri HeidiSQL, lalu buka tab **Query**.
2. Copy-paste dan jalankan blok berikut **seluruhnya**:

```sql
-- Pastikan nama database yang aktif sudah benar.

START TRANSACTION;

-- Lihat nilai sebelum perubahan.
SELECT
    id,
    dropdown_id,
    JSON_UNQUOTE(
        JSON_EXTRACT(menu_vars, '$[0].menu_name')
    ) AS menu_name,
    JSON_EXTRACT(
        menu_vars, '$[0].menu_icon'
    ) AS menu_icon_sebelum
FROM ml_dropdown_menu
WHERE id = 2
  AND dropdown_id = 2;

-- Ganti hanya ikon MGS5 EV yang masih berupa array kosong.
UPDATE ml_dropdown_menu
SET menu_vars = JSON_SET(
    menu_vars,
    '$[0].menu_icon',
    'contents/userfiles/menu_icon/202601/a7944e889e259f14dd067c680de5912c.png'
)
WHERE id = 2
  AND dropdown_id = 2
  AND JSON_UNQUOTE(
      JSON_EXTRACT(menu_vars, '$[0].menu_name')
  ) = 'MGS5 EV'
  AND JSON_TYPE(
      JSON_EXTRACT(menu_vars, '$[0].menu_icon')
  ) = 'ARRAY'
  AND JSON_LENGTH(
      JSON_EXTRACT(menu_vars, '$[0].menu_icon')
  ) = 0;

-- Seharusnya bernilai 1 jika data sesuai dump dan belum diperbaiki.
SELECT ROW_COUNT() AS jumlah_baris_diubah;

-- Periksa nilai setelah perubahan.
SELECT
    id,
    dropdown_id,
    JSON_UNQUOTE(
        JSON_EXTRACT(menu_vars, '$[0].menu_name')
    ) AS menu_name,
    JSON_TYPE(
        JSON_EXTRACT(menu_vars, '$[0].menu_icon')
    ) AS menu_icon_type,
    JSON_UNQUOTE(
        JSON_EXTRACT(menu_vars, '$[0].menu_icon')
    ) AS menu_icon_setelah

  AND dropdown_id = 2;
```

3. Jika database sudah benar, `jumlah_baris_diubah = 1`, nama **MGS5 EV**, dan tipe ikon **STRING**, jalankan ini **pada koneksi HeidiSQL yang sama**:

```sql
COMMIT;
```

Jika hasil tidak sesuai atau Anda ingin membatalkan, jalankan ini sebagai gantinya:

```sql

```

**Jangan jalankan `COMMIT` dan `ROLLBACK` sekaligus.** Segera pilih salah satunya setelah pemeriksaan agar transaksi tidak dibiarkan terbuka. Setelah `COMMIT`, reload website.
