# Editorial Journal redesign preview

Status: visual concept only. No production source files were modified for this preview.

## Direction v2 — modern and elegant

- Preserve the current Editorial Journal DNA: clean sans-serif typography, white surface, navy hierarchy, purple CMS accent, rounded media, featured story split, and article grid.
- Use a modern CMS editorial system: stronger type scale, tighter hero composition, cool neutral surfaces, controlled borders, and restrained elevation.
- Keep the masthead compact and useful instead of adding decorative issue/monogram elements.
- Keep the featured story as text on the left and image on the right, but place both in one balanced surface so the whitespace feels intentional.
- Keep the category rail, search action, three-card story grid, and visible pagination aligned with the existing template contract.
- Use equal-height card bodies, consistent media ratios, and stable metadata alignment.
- Mobile preserves the text-first reading order, stacks the hero media, keeps the category rail reachable, and collapses the story grid to one column.

## UI/UX checks applied

- Modern sans-serif stack; no serif, paper tone, monogram, or vintage display treatment.
- Visible focus states and keyboard-reachable links.
- No emoji icons; search and arrow icons are inline SVG.
- Touch-friendly category and pagination targets.
- No horizontal overflow at the mobile breakpoint.
- Reduced-motion override included.

Open `index.html` in a browser to review the responsive concept. This preview does not change the active Editorial Journal Blade template, frontend CSS, manager preview, or persisted template settings.
