# Arunika Aurora mobile preview set

Tanggal: 2026-09-04  
Use case: `ui-mockup`  
Tool: built-in `image_gen`

## Preview set

- `aurora-dashboard-closed.png`: dashboard mobile tertutup, header 64px, panel/menu toggle kiri, avatar kanan, statistik 2×2, dan chart.
- `aurora-profile-sheet.png`: profile sheet dari avatar topbar, pointer di bawah avatar, Profile, Settings, Dark Mode, Theme Color, dan Logout.
- `aurora-sidebar-open.png`: drawer kiri sekitar 80vw, ambient Aurora wash, menu desktop-consistent, active Dashboard, dan footer Awesome Admin.

## Visual constraints

Mempertahankan identitas Aurora: white/cool off-white, wash biru-mint-lavender, text blue-gray, active teal/green, outline icon tipis, shadow ringan, tanpa browser/OS chrome, tanpa device frame, tanpa menu tambahan, dan tanpa duplikasi profile card pada drawer.

## Status

Preview-only. Belum ada perubahan source production, database, route, atau Graphify.
