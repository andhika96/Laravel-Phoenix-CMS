# Arunika Aurora mobile preview redesign v2

Tanggal: 2026-09-04  
Use case: `ui-mockup`  
Tool: built-in `image_gen`

## Preview set

- `aurora-dashboard-closed-v2.png`: dashboard mobile tertutup dengan komposisi aurora ribbon baru, statistik 2×2, chart, avatar kanan, dan icon panel desktop di kiri.
- `aurora-profile-sheet-v2.png`: profile sheet baru dengan pointer tepat di bawah avatar dan icon panel desktop pada header.
- `aurora-sidebar-open-v2.png`: drawer sekitar 80vw dengan aurora ribbon, menu flat, icon panel desktop untuk close, active Dashboard, dan footer Awesome Admin.

## Icon contract

Semua state memakai bahasa icon desktop Aurora: rounded panel outline, vertical divider, dan chevron. State tertutup mengarah ke kanan; drawer terbuka memakai chevron ke kiri. Tidak menggunakan hamburger atau X.

## Status

Preview-only. Source production, database, route, dan Graphify tidak diubah.
